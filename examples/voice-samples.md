# Example Voice Samples — SYNTHETIC DEMONSTRATION ONLY

These three samples are invented for documentation purposes. They describe a fictional
author ("the example author") and must never be treated as a real person's writing.
Real user samples must never be committed to this repository.

## Sample 1 (explanatory note)

> I keep my explanations short. Each paragraph makes one point, and I move on.
> When something is complicated, I split it into steps. For example, I define the term
> first, then show how it behaves, then note the exception. That order works for me.

## Sample 2 (technical note)

> The function returns a JSON object with word counts and sentence statistics. It uses
> only the standard library, so there is nothing to install. However, the output is
> approximate: sentence splitting follows punctuation, and readability scores are
> estimates. Check the flags field before trusting any single number.

## Sample 3 (casual note)

> That draft is close, but the middle paragraph runs long. I would split it in two and
> cut the filler in the second half. The tone is fine, so I would leave that alone.

## What to notice (for the profile example)

- Mostly medium-length sentences with occasional short ones.
- Direct, moderately formal tone; first-person perspective.
- Short-to-medium paragraphs, one focus each.
- Moderate transitions (however, for example, so) tied to real logical relations.
- Technical terms kept exact; no slang; no decorative language.
